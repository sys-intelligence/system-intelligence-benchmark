Docker image for the System Intelligence Benchmark CourseLab tasks for MIT 6.1810 Operating System Engineering labs.

Build and push the image:

```bash
docker build -t sysintelligence/xv6:latest .
docker push sysintelligence/xv6:latest
```

**Note:** You must be part of the Docker Hub organization with write access to push the image.

If you encounter any issues, please open a GitHub issue.
